# ReactNativeReadApp

Stalker Books — застосунок для читання від української спільноти шанувальників Сталкера. Android, iOS (телефони й планшети) і Web.

## Технології

| Що                   | Технологія                                                        |
| -------------------- | ----------------------------------------------------------------- |
| Фреймворк            | Expo SDK 57, React Native 0.86, React 19                          |
| Мова                 | TypeScript (strict)                                               |
| Навігація            | Expo Router (маршрути — файли в `src/app/`)                       |
| Стан                 | zustand                                                           |
| Сховище на телефоні  | JSON-файли через `expo-file-system`                               |
| Сховище у браузері   | IndexedDB (`idb-keyval`)                                          |
| Довгі тексти й сітки | `@shopify/flash-list` (віртуалізація)                             |
| Шрифти книг          | `@expo-google-fonts/*` (Literata, PT Serif, Tinos, Arimo, Roboto) |
| Яскравість           | `expo-brightness`, повзунки — `@react-native-community/slider`    |
| Якість коду          | ESLint (`eslint-config-expo`) + Prettier                          |

## Що потрібно

| Програма                                   | Навіщо             | Перевірка                  |
| ------------------------------------------ | ------------------ | -------------------------- |
| [Node.js 22+](https://nodejs.org) (з npm)  | збірка й запуск    | `node -v`                  |
| [Git](https://git-scm.com)                 | клонування         | `git --version`            |
| [Expo Go](https://expo.dev/go) на телефоні | запуск на телефоні | версія з підтримкою SDK 57 |

Телефон і комп'ютер мають бути в одній Wi-Fi мережі. Expo CLI окремо встановлювати не треба — він у залежностях проєкту.

## Запуск

```powershell
git clone https://github.com/Dmytrii9Cherniak/ReactNativeReadApp.git
cd ReactNativeReadApp
npm install
npx expo start
```

- **Телефон:** відсканувати QR-код у терміналі в Expo Go (Android) або камерою (iOS).
- **Браузер:** клавіша `w` у терміналі → http://localhost:8081.

Зупинка — `Ctrl+C`.

## Можливості

- **Навігація:** на телефоні меню виїжджає зліва (☰ або свайп від краю), на планшеті воно постійно видно збоку.
- **Вхід і ролі:** реєстрація з кодом з пошти, вхід, вихід; ролі `user` і `admin` — меню й розділи залежать від ролі. Гість бачить бібліотеку, читання і «Біля вогнища».
- **Бібліотека:** сітка обкладинок з пошуком; сторінка книги; полиці «Мої книги».
- **Читання:** текст книги, панель «Aa» (яскравість, розмір, шрифт: Literata, PT Serif, Times New Roman, Arial, Roboto), позиція зберігається — «Продовжити · 34%».
- **Ранги:** досвід (XP), 10 рангів з назвами для кожного з 7 угруповань, ендгейм «Чорнобиль» / «Моноліт», бейдж «non stop», профіль з блоком «Сьогодні», вибір угруповання раз на 30 днів.
- **Біля вогнища:** стрічка історій, сторінка історії, нова історія (1 на день), вогники.
- **Завантаження книги** → **Перевірка надісланого** (книги й історії) → поява в бібліотеці / стрічці.
- **Адмінка** (лише admin): огляд з цифрами, черга книг та історій (схвалити / відхилити з причиною, редагувати, приховати, видалити), користувачі (роль, блокування, досвід), журнал дій, оголошення всім. Лічильник нових заявок у меню оновлюється наживо.
- **Сповіщення:** автор дізнається, що книгу чи історію схвалили або відхилили (з причиною), про зміну досвіду й оголошення.
- **Налаштування**, **Про застосунок**, **Умови використання**.
- **Акаунт:** відновлення пароля кодом з пошти, зміна ніку, пошти й пароля, видалення акаунта, «показати пароль».
- **Мої надсилання:** книги й історії зі станом перевірки й причиною відхилення.
- **Рідер:** завантажені EPUB читаються (текст і зміст розбирає тестовий сервер, як потім бекенд), «Зміст» з переходом до розділу, «Продовжити читання» в бібліотеці. Обкладинки з картинкою, заглушка — якщо картинка не завантажилась.
- **Меню:** на телефоні — свайп від лівого краю; на планшеті й web — бокова панель, яку можна згорнути до іконок (запам'ятовується).
- **Офлайн:** плашка «Немає мережі»; книги можна завантажити й читати без інтернету (розділ «Завантажені»).
- **Рідер+:** закладки й цитати (довге натискання на абзац), пошук у тексті, озвучення (expo-speech), теми «Зона / Сепія / Ніч», поля й вирівнювання.
- **Статистика й досягнення:** хвилини за день, ціль, серія днів, тиждень; 11 досягнень зі сповіщеннями.
- **Рейтинг угруповань** за тиждень; **Поділитися** книгою, історією чи цитатою.
- **Мови:** українська (за замовчуванням) і англійська.

### Демо-режим

Бекенду ще немає — дані віддає тестовий сервер `src/mock-backend` (зберігається на пристрої). На екрані входу є підказка з акаунтами:

| Роль  | Пошта                 | Пароль     |
| ----- | --------------------- | ---------- |
| admin | `admin@stalker.books` | `admin123` |
| user  | `user@stalker.books`  | `user123`  |

Код підтвердження при реєстрації — `123456`. Контракт для бекенду — [docs/API.md](./docs/API.md).

## Структура

```
src/
  app/          маршрути Expo Router (тонкі обгортки над екранами фіч)
  features/     auth, catalog, book, shelves, reader, settings, progression, campfire,
                upload, admin, notifications, about, navigation
  mock-backend/ тестовий сервер до появи бекенду
  shared/       UI-компоненти, тема, мови (i18n), хуки, утиліти
  config/       змінні середовища
docs/API.md     контракт API для бекенду
```

Правила коду й архітектура — [ARCHITECTURE.md](./ARCHITECTURE.md).

## Типові проблеми

| Симптом                                      | Що зробити                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Expo Go не відкриває застосунок              | одна Wi-Fi мережа, вимкнути VPN; або `npx expo start --tunnel`                                   |
| Після змін застосунок працює «по-старому»    | `npx expo start -c` і повністю перезапустити Expo Go                                             |
| Expo Go пише, що проєкт несумісний           | Expo Go з магазину підтримує лише останній SDK; Android — потрібна версія на https://expo.dev/go |
| Скинути демо-дані                            | видалити застосунок з Expo Go / очистити дані сайту в браузері                                   |
| `npm run lint`: «Cannot find native binding» | `npm rebuild unrs-resolver`                                                                      |
