# ReactNativeReadApp

Рідер для iOS, Android і Web: PDF, EPUB, TXT. Expo SDK 57, React Native, TypeScript, Expo Router, zustand.

## Запуск

```bash
npm install
npx expo start          # QR → Expo Go на телефоні; w — у браузері
npm run check           # typecheck + ESLint + Prettier
```

PDF на iOS / Android з'явиться разом із власною збіркою (EAS, профіль `development` у eas.json).

Структура та правила — [ARCHITECTURE.md](./ARCHITECTURE.md).
