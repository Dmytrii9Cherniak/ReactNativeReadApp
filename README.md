# ReactNativeReadApp

Рідер книг для Android, iOS і Web: TXT, PDF, EPUB. Працює повністю офлайн — усі дані (бібліотека, прогрес читання, статистика й ранги) зберігаються на пристрої. Сервера й бази даних немає.

## Технології

| Що                  | Технологія                                                     |
| ------------------- | -------------------------------------------------------------- |
| Фреймворк           | Expo SDK 57, React Native 0.86, React 19                       |
| Мова                | TypeScript (strict)                                            |
| Навігація           | Expo Router (маршрути — файли в `src/app/`)                    |
| Стан                | zustand                                                        |
| Сховище на телефоні | JSON-файли через `expo-file-system`                            |
| Сховище у браузері  | IndexedDB (`idb-keyval`)                                       |
| PDF                 | `react-pdf` (лише web; на телефоні — після власної збірки EAS) |
| Великі TXT          | `@shopify/flash-list` (віртуалізований список рядків)          |
| Якість коду         | ESLint (`eslint-config-expo`) + Prettier                       |

## Що потрібно

| Програма                                   | Навіщо             | Перевірка                  |
| ------------------------------------------ | ------------------ | -------------------------- |
| [Node.js 22+](https://nodejs.org) (з npm)  | збірка й запуск    | `node -v`                  |
| [Git](https://git-scm.com)                 | клонування         | `git --version`            |
| [Expo Go](https://expo.dev/go) на телефоні | запуск на телефоні | версія з підтримкою SDK 57 |

Телефон і комп'ютер мають бути в одній Wi-Fi мережі. Expo CLI окремо встановлювати не треба — він у залежностях проєкту.

## Запуск

```powershell
git clone https://github.com/Dmytrii9Cherniak/ReactNativeReadApp.git
cd ReactNativeReadApp
npm install              # + копіює воркер pdf.js у public/
npx expo start
```

- **Телефон:** відсканувати QR-код у терміналі в Expo Go (Android) або камерою (iOS).
- **Браузер:** клавіша `w` у терміналі → http://localhost:8081.

Зупинка — `Ctrl+C`.

## Можливості

- **Бібліотека:** імпорт PDF / EPUB / TXT з пристрою, видалення (довге натискання), прогрес кожної книги.
- **TXT:** читання з віртуалізацією (великі файли не гальмують), збереження позиції.
- **PDF:** читання на web зі збереженням сторінки; на телефоні — після власної збірки (EAS, профіль `development` в `eas.json`).
- **EPUB:** ще в розробці.
- **Статистика й ранги:** прочитані умовні сторінки за день і загалом, 7 рангів (вкладка «Профіль»). Рахується лише просування вперед.

## Команди

| Команда                        | Що робить                                                     |
| ------------------------------ | ------------------------------------------------------------- |
| `npx expo start` / `npm start` | запуск (QR, `w` — браузер)                                    |
| `npm run web`                  | запуск одразу в браузері                                      |
| `npm run check`                | typecheck + ESLint + Prettier — **перед кожним комітом**      |
| `npm run typecheck`            | лише TypeScript                                               |
| `npm run lint` / `lint:fix`    | ESLint / з автовиправленням                                   |
| `npm run format`               | відформатувати все Prettier                                   |
| `npm run doctor`               | перевірка конфігурації Expo                                   |
| `npx expo install <пакет>`     | **єдиний** спосіб додавати пакети: підбирає версію під SDK 57 |

## Структура

```
src/
  app/          маршрути Expo Router (тонкі обгортки над екранами фіч)
  features/     library, reader, stats, settings — самодостатні модулі
  shared/       UI-компоненти, тема, утиліти (не знають про фічі)
  config/       змінні середовища
scripts/
  copy-pdf-worker.js   postinstall: воркер pdf.js → public/
```

Правила коду й архітектура — [ARCHITECTURE.md](./ARCHITECTURE.md).

## Типові проблеми

| Симптом                                      | Що зробити                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Expo Go не відкриває застосунок              | одна Wi-Fi мережа, вимкнути VPN; або `npx expo start --tunnel`                                   |
| Після змін застосунок працює «по-старому»    | `npx expo start -c` і повністю перезапустити Expo Go                                             |
| Expo Go пише, що проєкт несумісний           | Expo Go з магазину підтримує лише останній SDK; Android — потрібна версія на https://expo.dev/go |
| PDF на телефоні показує заглушку             | очікувано: PDF на телефоні з'явиться з власною збіркою (EAS)                                     |
| `npm run lint`: «Cannot find native binding» | `npm rebuild unrs-resolver`                                                                      |
