# ReactNativeReadApp

Рідер для iOS, Android і Web для PDF, EPUB і TXT. Expo SDK 57, React Native, TypeScript, Expo Router, zustand.

## Запуск

```bash
npm install
npx expo start          # QR-код → Expo Go на телефоні, w — у браузері
npm run typecheck
```

Структура та правила — [ARCHITECTURE.md](./ARCHITECTURE.md).
