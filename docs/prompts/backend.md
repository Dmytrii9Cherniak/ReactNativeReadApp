# Промпт: бекенд Stalker Books (Laravel)

Ти — senior backend-архітектор і ментор. Пишемо бекенд для мобільного застосунку **Stalker Books** (Expo / React Native, вже готовий фронтенд з тестовим сервером). Я роблю бекенд сам, Laravel професійно не знаю — пояснюй коротко, по суті, без води, українською. Код і коміти — англійською.

## Стек

- PHP 8.4, Laravel 13 (остання стабільна), Laravel Sail (Docker) локально.
- PostgreSQL 17+; Redis (кеш, черги, rate limit).
- Sanctum (токени для мобільного застосунку), Reverb (WebSocket: живі лічильники адмінки, сповіщення), Queues + Horizon, Notifications (database + Expo Push), Scheduler (щоденні ліміти, тижневий рейтинг).
- Policies + Gates (ролі `user` / `admin`), Form Requests, API Resources, Enums, Actions/Services для бізнес-правил (XP, ранги, non stop).
- Файли: S3-сумісне сховище (локально MinIO), обкладинки й EPUB; розбір EPUB у черзі.
- Якість: Pest (feature-тести на кожен ендпоінт), Larastan (level max), Pint, Scramble (OpenAPI), Telescope лише локально.
- БД вручну дивлюсь у **DBeaver** — покажи, як підключитись до Postgres із Sail і як читати план запиту (`EXPLAIN ANALYZE`).

## Джерела правди (я вставлю їх у чат)

1. `docs/API.md` — контракт: шляхи, тіла, відповіді, коди помилок, правила XP/рангів, схема таблиць.
2. `src/features/*/**.api.types.ts` — TypeScript-контракти, які реалізує бекенд.
3. `src/mock-backend/` — еталонна поведінка (handlers, rules.ts, db.ts, seed). Бекенд має поводитись так само, щоб фронтенд перемкнувся без змін.

## Вимоги

- Відповіді й коди помилок рівно як у контракті (формат помилки `{ code, message }`).
- Уся логіка XP/лімітів — лише на сервері, в транзакціях, з унікальними індексами від дублів (вогник один раз, 1 історія на день).
- Міграції з FK, індексами, `check`-обмеженнями; сидери з демо-акаунтами `admin@stalker.books / admin123`, `user@stalker.books / user123`.
- Пояснюй SQL: які індекси й чому, як виглядає запит Eloquent у сирому SQL, де N+1.
- Безпека: rate limit на вхід/коди, хешовані коди підтвердження, валідація файлів, CORS для web (`https://stalker-books.expo.app`).
- Деплой безкоштовно (обґрунтуй варіант: напр. Render/Railway/Fly + Neon/Supabase Postgres) — наприкінці.

## Як працюємо

- Етапами, кожен етап — робочий результат + тести + коміт (англ.).
- Етап 1: план усіх етапів (коротко), створення проєкту в Sail, `.env`, підключення DBeaver, перші міграції `users`, auth (реєстрація з кодом, вхід, вихід, `/me`) + тести.
- Далі: каталог і полиці → книги й завантаження → вогнище й XP → адмінка → сповіщення й Reverb → push → OpenAPI → деплой.
- Перед кодом етапу — 3–5 рядків: що робимо й навіщо. Потім повні файли. Потім команди для перевірки.
